# Interactive Data Visualization with Plotly

This repository contains the honors tutorial project for **CMSE 402** on using [Plotly](https://plotly.com/python/) to create interactive visualizations.
## Contents

- Why Plotly?
- Overview of Plotly Library
- Description of the Billionaires Dataset
- Step-by-Step Tutorials on:
  - Bar Charts
  - Scatter Plots
  - Box Plots 
  - Heatmaps
  - Treemaps
  - Choropleths
- Summary and Reflection

## Files

- `CMSE_402HonorsProject.ipynb` — Jupyter Notebook tutorial with complete code and explanations
- `CMSE_402HonorsProject.html` — HTML version for quick and local viewing

## Dataset

This project uses the [Billionaires Statistics Dataset](https://www.kaggle.com/datasets/nelgiriyewithana/billionaires-statistics-dataset), which contains information on global billionaires, including net worth, country, industry, and more.

## View the Tutorial

You can view the interactive tutorial by: 
- Downloading the Jupyter notebook and viewing it in Anaconda Navigator/ Jupypter Hub
- Downloading the .html file and viewing it locally on your computer
